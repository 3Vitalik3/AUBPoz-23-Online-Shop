## Программная инженерия, часть 2, курсовой проект

# Создайте сайт интернет магазина. 
# На сайте должно быть 2 роли, покупатель и администратор. 
# Покупатель может заходить в свой личный кабинет, корзин и страницу товаров.
# На странице товаров он может добавлять товары в корзину, производить фильтрацию товаров и открывать страницу товара, что бы посмотреть более подробную информацию о нем.
# Если пользователь покинул сайт при следующем заходе на него его корзина должна быть в том-же состоянии, что и в прошлой сессии 
# Администратор может создавать новыые товары, редактировать и удалять их.


## 1. Цель проекта
Цель - разработать веб‑приложение интернет‑магазина с поддержкой ролей покупатель и администратор.
Приложение реализовано на Java с использованием Spring Boot и шаблонизатора Thymeleaf. Данные хранятся в базе H2.

## 2. Постановка задачи
Требуется реализовать сайт интернет‑магазина со следующими возможностями:

# 2.1 Роли
Покупатель (ROLE_USER)
Администратор (ROLE_ADMIN)
# 2.2 Возможности покупателя
Доступ к:
странице товаров;
развернутой странице товара (подробная информация);
корзине;
личному кабинету;
фильтрация по названию и цене;
добавление товара в корзину;
переход на страницу товара.
Корзина должна сохраняться между заходами (после закрытия сайта состояние корзины не теряется для того же пользователя).
# 2.3 Возможности администратора
создание;
редактирование;
удаление

## 3. Аутентификация и роли

Страница входа: /index используется попап
После входа пользователь попадает на /products
Доступ к /admin/** разрешен только роли ROLE_ADMIN
# 3.2 Страницы покупателя
/catalog - список товаров
/products/{id} - страница товара
/cart - корзина пользователя
/profile - личный кабинет
# 3.3 Корзина (сохранение состояния)
Состояние корзины сохраняется

# 3.4 Админка
/pages/admin.html - список товаров
/admin/products/new - создание товара
/admin/products/{id}/edit - редактирование
удаление выполняется POST‑запросом /admin/products/{id}/delete
